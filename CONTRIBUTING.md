# Contributing

BaguetteDB doesn't accept code contributions for now: pull requests from outside the project are closed without
review. Contributions will open, with a contributor license agreement, once that changes.

Issues are welcome:

- **Bugs:** include the version (`bdb version`), what you did, what you expected and what happened.
- **Feature requests:** describe the problem you want solved, not only the solution.
- **Questions:** anything the README and DEVELOPMENT.md don't answer.
