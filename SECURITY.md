# Security

Please don't report security vulnerabilities through public issues. Instead, open the repository's
[Security tab](https://github.com/alexandremgo/baguettedb/security) and click **Report a vulnerability**. Only you and
the maintainer see the report.

Include the version (`bdb version`), how to reproduce the issue and what an attacker could do with it. Once a fix
ships, an advisory credits you, unless you'd rather not be named.

Thank you for helping keep BaguetteDB and its users safe.
